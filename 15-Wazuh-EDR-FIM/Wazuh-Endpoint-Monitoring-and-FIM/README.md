# Wazuh Endpoint Monitoring & File Integrity Monitoring

## Overview

Hands-on Wazuh endpoint security exercises completed during EC-Council Certified SOC Analyst (CSA) training in a controlled virtual lab environment.

The exercises focused on endpoint monitoring, File Integrity Monitoring (FIM), authentication activity, and detection of suspicious endpoint behavior.

---

## Objectives

- Understand endpoint security monitoring
- Deploy Wazuh agents
- Monitor Linux and Windows endpoints
- Practice File Integrity Monitoring
- Detect file creation, modification, and deletion
- Monitor authentication failures
- Observe suspicious process and listener activity
- Connect endpoint telemetry with SOC investigation and incident response

---

## Wazuh Environment

Wazuh was used as the endpoint monitoring and security platform.

Agents were deployed on:

- Kali Linux
- Windows

The endpoints generated security activity that was then observed through the Wazuh platform.

---

## Wazuh Agent Deployment

A Wazuh agent was deployed on Kali Linux and connected to the Wazuh server.

The agent was used to collect endpoint security information and demonstrate how endpoint telemetry can be monitored centrally.

A Windows agent was also configured for endpoint monitoring exercises.

---

## File Integrity Monitoring

File Integrity Monitoring (FIM) was practiced on both Linux and Windows systems.

The exercises demonstrated how changes to monitored files can generate security events.

### Linux FIM Exercise

On the Kali Linux endpoint, file activity was generated by:

- Creating a file
- Adding or changing file content
- Deleting the file

Wazuh was then used to observe the resulting file-integrity events.

Authentication Monitoring

Authentication activity was monitored using Wazuh.

A controlled SSH authentication-testing exercise generated multiple failed login events against the Kali Linux endpoint.

Wazuh was used to observe the resulting authentication failures.

This demonstrated how endpoint telemetry can help identify potential brute-force or unauthorized-access activity.

Unauthorized Process / Listener Monitoring

A Netcat listener was started in the controlled lab environment to generate endpoint activity.

Wazuh was used to observe information associated with the process/listener.

This exercise demonstrated how endpoint monitoring can provide visibility into processes and network listeners that may require investigation.
